# Image Stitching Tool

用于拼接扫描平台拍摄的规则网格图像（例如 `11.png` 到 `88.png`）。

## 功能

- 支持导入 `png/jpg/jpeg/tif/tiff`
- 支持两种导入方式：选择目录扫描 / 手动多选图像
- 按文件名中的行列编号进行同向逐行排序（`11 -> 12 -> ... -> 88`）
- 支持独立设置横向和纵向重叠度
- 支持手动指定期望行列数（不填则自动识别）
- 支持不同分辨率图片拼接（可选统一缩放/补边/严格模式）
- 支持亮度统一（重叠区估计增益和偏移）
- 支持可选自动微调对齐
- 支持拼接进度条和实时状态提示
- 缺图时阻止导出并明确提示缺失编号
- 导出完整大图（PNG/TIFF/JPEG）

## 安装

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

## 命名规则

- 文件名格式为两位数字：`rowcol.ext`
- 例如：`11.png`, `12.png`, ..., `88.png`

## 注意

- 分辨率处理模式默认是“统一到首张分辨率（推荐）”
- 缺图时会停止并报错，不允许带缺口导出
