## Requirements

An installation of the [Vimba X SDK](https://www.alliedvision.com/en/products/software/vimba-x-sdk/) is required to use this plugin.

This plugin also needs the [VmbPy](https://github.com/alliedvision/VmbPy) Python library. It can be installed from the `.whl` found as part of the Vimba X SDK installation, or downloaded from the associated GitHub release page.

Note: It is not possible to use this plugin without the Vimba X SDK!
